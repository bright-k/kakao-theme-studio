# 0.3.0 화면별 편집 검토

리소스를 먼저 모아서 등록한 뒤 미리보기 화면을 넘기던 구조를 화면 선택 → 그 화면의 원본·상태·배율·색상 조정 → 양 플랫폼 확인 → 다음 화면 이동 흐름으로 변경했다. 친구, 채팅 목록, 채팅방, 잠금화면, 배너·버튼, 아이콘·시작화면을 자유롭게 이동한다.

공통 원본과 iOS/Android 세부 편집기를 미리보기 옆에 배치했다. 전체 카탈로그와 같은 편집기를 사용해 지원 항목이 어긋나지 않게 했다. 원본 전체 프로필 3개, 탭 선택 8개, 말풍선 연속/선택, 친구 추가 기본/누름 등 기존에 세부 이미지에서만 접근하던 공통 입력도 모두 노출했다. 전체 이미지에서는 모든 물리 배율·가로·태블릿 출력을 선택할 수 있다. 비밀번호 1~4의 입력 전·후 8개와 iOS 키패드 눌림, Android 패턴 색상도 그대로 지원한다.

목록 배경·탭·프로필의 실제 공통 적용 범위를 안내한다. 화면별 초기화는 현재 표시된 항목에만 적용해 다른 화면 재정의를 지우지 않는다. 전체 대화상자를 닫으면 현재 화면의 옆 패널로 돌아간다. 생성 규칙·키·프로젝트 스키마는 변경하지 않았다.

## 누락 방지 근거

- 확보한 공식 26.9.0 카탈로그 전체: iOS 속성 105, Android 색상 49, 이미지 논리 그룹 82 / 출력 슬롯 146.
- 공통 원본 슬롯 47개를 화면 편집과 전체 원본 목록 양쪽에서 제공한다.
- screen-model과 audit-screens가 모든 항목의 편집 화면을 기록하고 미분류를 차단한다. 세부 매핑은 screen-coverage.json과 SUPPORT-MATRIX.md에 있다.
- 단위·회귀 20개 통과. 화면별 브라우저 테스트는 실제 DOM 항목을 전 카탈로그와 대조하고 색상 변경의 Canvas 픽셀, 다른 화면 초기화 보존, 전체 목록 복귀와 작은 화면을 검증했다.
- 기존 편집기 회귀와 브라우저 제작 흐름도 통과했다. 임시 키로 실제 iOS/Android 생성·APK 다운로드·개인키 없는 프로젝트 백업을 확인했다. 테스트는 격리한 .test-data에서 수행했다.

## 검증 경계

지원 범위는 확보한 공식 26.9.0 샘플과 문서상 보완 항목이다. 임의 버전의 모든 구성이나 실제 카카오톡 적용 성공을 의미하지 않는다. 캔버스는 대표 화면이며 세부 상태·가로·태블릿은 이미지 탭에서 실제 출력 파일을 검토한다. 스플래시는 Android 12 미만 대상이다. iOS 오픈채팅은 공식 샘플에서 지금(Now) 아이콘을 함께 사용한다. 실제 카카오톡/iPhone 적용은 미검증이며 deviceVerified는 false를 유지한다.
