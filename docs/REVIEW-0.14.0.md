# 0.14.0 사용성 개선 (2026-10-31)

REVIEW-USABILITY-0.13.1.md의 제안과 상단 수동 저장·생성 진행 표시 요청을 구현했다. 앱과 compilerVersion을0.14.0으로 갱신했다. 기존51개 공통 원본·16개 플랫폼 입력·39개 공통색·146개 출력 계약을 유지한다.

## 저장과 복구

- 상단 저장 버튼은 변경됨/저장 중/저장됨/입력 오류/연결 실패/복구 충돌을 구분한다. 클릭 또는 ⌘/Ctrl+S로 수동 저장한다.350ms 자동 저장과80/160ms 미리보기 갱신은 별도로 유지한다.
- 편집 즉시 브라우저 localStorage에 임시본을 쓰고 서버의 프로젝트별 editor-drafts.json에도 보관한다. 키 비밀번호·키 파일은 포함하지 않는다. 저장·명시적 버림 후 순번 tombstone으로 늦게 도착한 요청이 임시본을 다시 살리지 못하게 한다.
- 같은 창의 같은 저장본 기준 임시 편집은 재접속 시 복구한다. 더 새로운 저장본이나 이전 창의 임시본과 충돌하면 복구/현재 저장본 선택을 표시한다. 다른 활성 창의 임시 편집은 자동 복구·삭제하지 않으며 해제 직전 서버가 다시 검사한다. 충돌 선택 전에는 편집을 잠가 새 변경이 사라지지 않게 한다. 복구는 프로젝트 실행취소로 되돌릴 수 있으며 현재 서명키 연결을 보존한다.
- 유효하지 않은 버전 등도 임시 보관할 수 있지만 정식 theme.json은 검증 통과 값만 저장한다. 임시본의 자산 참조도 에셋 이동·영구 삭제 직전 transaction에서 보호한다. 서버 재시작 후에도 보호하며 ZIP 백업·복제에는 임시본을 포함하지 않는다.
- 필드 오류를 aria-invalid와 인접 오류 문구로 유지하고 상단 오류 목록에서 이동한다. 연결 실패는 입력 오류와 구분하며 저장 버튼/온라인 복귀로 재시도한다. 텍스트·숫자 입력의 실행취소는 입력란에 맡기고 체크박스·일반 디자인 조작은 프로젝트 실행취소를 유지한다.

## 생성 진행

- 우하단 고정 카드에 프로젝트명, 현재 실제 단계, 경과 시간, 진행한 단계와 상태를 표시한다. 모바일에서는 위치 이동 버튼 위에 둔다. 생성 버튼도 생성 중으로 바뀐다.
- 서버 작업이 기록한 리소스 변환→iOS 패키징→Android 컴파일→코드 생성→정렬/서명→검증 단계를 사용한다. 실제 비율을 측정하지 않으므로 임의의 퍼센트 대신 indeterminate 진행 표시를 쓴다.
- 연결 재시도, 실패, iOS만 완료된 부분 성공, 전체 성공을 구분한다. 완료 카드에서 생성 결과로 이동한다. 브라우저 새로고침은 sessionStorage의 작업 ID로 이어서 조회한다. 작업 ID는 비밀 정보가 아니며 인증은 기존 세션을 사용한다.
- 서버 프로세스 재시작 후 작업 Map 자체의 복구는 아직 지원하지 않는다. 해당 경우 상태를 확인할 수 없다고 안내하고 최근 생성 결과/재생성으로 연결한다. 성공을 추정하지 않는다.
- 제작 버튼 부근에 저장/미리보기 반영/최근 생성 일치 상태를 모은다. 이전 컴파일러 또는 변경된 프로젝트의 결과 경고를 유지한다.

## 편집과 미리보기

- 배경 이미지의 주 동작은 등록하고 적용이다. 단색에서 등록하면 양 플랫폼 이미지 모드를 켠다. 원본만 등록은 현재 모드를 유지한다. 공통 본체의 기존 자동 활성화 계약은 유지한다.
- 배경 패널에 현재 iOS/Android 색/이미지 적용 상태, 색상·이미지 예외 보기, 명시적 공통 연결 동작을 제공한다. 예외를 자동 삭제하지 않으며 등록 원본·크롭·개별 가이드는 보존한다.
- 실제 플랫폼 투영의 본체·글자색과 공통색/플랫폼 예외로 대비를 검사한다. iOS 선택 상태는 생성 PNG의 본체 내부 픽셀을 검사한다. 이미지 본체나 확정할 수 없는 반투명 색에는 단색 대비 성공을 주장하지 않는다. 경고는 설정으로 연결하며 디자인을 자동 수정하지 않는다.
- 말풍선/배경/입력창/색상/이미지/전체 작업 분류와 접힌 고급 항목으로 핵심 편집에 바로 접근한다. 미리보기 클릭·검색은 필요한 전체 설정을 열고 기존 catalog-editor 한 인스턴스를 재사용한다.
- 작은 화면은 한 플랫폼을 기본으로 하며 플랫폼 전환, 미리보기/설정 빠른 이동과 프로젝트 도구를 제공한다. 저장·생성 버튼은 가로 스크롤에 숨지 않는다.
- 한 글자/짧은 문장/여러 줄/사용자 문장과 명시적 줄바꿈을 지원한다. 받은 첫·연속/보낸 첫·연속 네 상태는 유지한다. 샘플·플랫폼·비교 상태는 프로젝트에 저장하지 않는다. 매우 긴 사용자 문장은 실제 채팅 영역에서 잘릴 수 있으므로 샘플 길이를 조정한다.
- 수정 전후 비교는 생성된 ImageBitmap을 독립 복제해 사용한다. 프로젝트 전환·기준 변경 때 닫으며 현재 비트맵과 생명주기를 분리한다. 비교 중에는 이전 그림을 편집 대상으로 선택하지 못하게 하고 디자인 편집을 시작하면 현재 모습으로 돌아온다.
- HEX 선택기에 최근 색/프로젝트 색을 제공한다. Android 선행 알파는 보존한다. 슬라이더 옆 숫자 입력은 원래 슬라이더 이벤트를 사용해 안전 범위·실행취소·생성 정책을 공유한다.

## 근거와 한계

검증 명령·캡처·결과는 VERIFICATION.md의0.14.0 절을 따른다. 모든 새 검증은 격리한 .test-data에서 수행하며 사용자 원본을 이동하지 않는다. 실제 카카오톡 인식·적용 검증은 여전히 미완료이고 deviceVerified/actualAppVerified=false다.
