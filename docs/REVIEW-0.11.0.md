# 0.11.0 플랫폼별 본체와 캐릭터 분리

플랫폼별로 본체 그림을 교체해도 공통 캐릭터가 합성되도록 별도의 입력 계층을 추가했다. `말풍선 본체와 캐릭터`의 보낸/받은·첫/연속 패널에서 `iOS 본체·캐릭터` 또는 `Android 본체·캐릭터`를 펼친다. 본체 이미지를 등록하면 해당 플랫폼만 변경하고 캐릭터는 기존 공통 설정을 따른다. `공통 캐릭터 설정 따르기`를 해제하면 이미지·사용 여부·크기·좌우 위치·세로 겹침·기준 모서리·앞뒤 순서를 그 플랫폼에서 조정할 수 있다. 빠진 필드는 상위 설정을 따르며 연속은 기존 공통 연속 정책과 첫 번째 플랫폼 설정을 함께 상속한다.

본체의 `공통 본체 따르기`와 캐릭터 설정 복귀는 독립적이다. 캐릭터 그림만 공통으로 되돌리는 것도 가능하다. 플랫폼 캐릭터를 선택해 드래그하면 해당 플랫폼의 배치만 바뀐다. 공통 캐릭터를 쓰는 플랫폼은 공통 배치를 편집한다. 기존80ms/160ms 갱신 큐와 undo를 사용한다. 캐릭터 위치·겹침은 본체 크기/내부 글자 여백을 바꾸지 않는다.

선택 필드 `bubblePlatforms.{ios,android}.{sent,received}`에 `body`와 `character`를 분리 저장하고, `group`에 연속 예외를 둔다. character는 image와 decorationEnabled/size/gap/offset/anchor/shiftX/placementY/layer를 받는다. 생성·미리보기·iOS 가이드·Android9-patch·provenance는 동일한 platformBubbleProject 투영을 사용한다. 공통 원본51개와 출력146개는 유지하며 카탈로그에 플랫폼별 입력16개와 채팅방 연결을 추가했다. compilerVersion0.11.0으로 캐시를 분리한다.

원본은 플랫폼별 body-source/character-source 역할에 불변 버전으로 저장한다. 검증·해시·자산 목록·이관·복제·백업/복원은 두 계층을 모두 포함한다. 저장/백업 버전은 변경하지 않으며 필드 없는 기존 프로젝트는 그대로 읽는다. 실제 사용자 설정을 새 방식으로 자동 전환하지 않는다.

기존 resourceOverrides는 최종 이미지이므로 계속 최우선이다. 해당 예외가 있으면 경고와 `본체·캐릭터 합성 적용`을 제공한다. 명시적으로 누를 때만 그 플랫폼·쪽·첫/연속의 최종 이미지 예외를 해제하고 가이드를 유지한다. 원본 파일은 삭제하지 않는다. 새 본체/캐릭터 입력에는 가이드 테두리 없는 PNG를 쓰며 `.9.png`는 기존 최종 출력 편집에서 지원한다. 플랫폼 늘림·여백은 기존 catalog-editor에서 별도로 조정한다.

전체 단위66개와 새 플랫폼 UI/픽셀/드래그/undo·기존 브라우저 회귀 및 실제 서명 APK/ktheme 생성이 통과했다. 실제 기기에서 카카오톡 적용은 사용자 확인 범위이며 deviceVerified=false다. 상세 근거는 VERIFICATION.md다.
