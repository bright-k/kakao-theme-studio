# 0.10.2 Android 합성 말풍선 가이드 보정

기존64×56 본체에 작성된 Android resourceGeometry를 캐릭터를 포함한 전체 PNG에 비례 적용하고 있었다. 예를 들어192×168의 stretchY66과 top42가 새 헤더/본체 전체 높이에 맞춰 늘어나면 늘림 띠는 캐릭터를 통과하고 글자 시작은 본체보다 위에 놓였다. 긴 문장은 그림 위로 벗어나고 본체만 아래에 남았다.

새 bubble-guides 모델은 명시 bodyRect가 있는 가이드를 그 본체에 맞춰 변환한다. 구형64:56 비율 레코드는 본체 전체를 참조 프레임으로 해석하고, 그 외 구형 합성 크기는 현재 본체의 비율 프레임을 사용한다. 이후 본체 이동과 헤더/외부 투명 여백을 별도로 더한다. 기존 저장 레코드와 원본 PNG는 자동으로 수정하지 않는다.

합성 말풍선의 늘림 띠는 캐릭터와 고정 모서리를 제외한 본체 내부로 제한한다. 내용 영역은 본체 안에 두고 최소 글자 크기에서도 고정 그림을 담을 여백을 확보한다. 다중 구간은 보호 범위에서 병합될 수 있다. 원본/출력 이미지 재정의가 있는 리소스는 기존 파일별 좌표 정책과 다중 구간을 유지한다.

합성 가이드는 논리 픽셀 경계에 맞춰 캐릭터가1픽셀 줄어드는 것을 방지한다. Canvas 폭·높이는 소수점1/3 여백의 부동소수점 오차를 제외하고 정수로 확정한다. 채팅과 전달 장면에 같은 원칙을 적용한다.

세부 시각 편집은 실제 적용된 출력 가이드를 보여 준다. 사용자가 편집할 때만 resourceGeometry에 선택 bodyRect(출력 픽셀 단위의 x/y/width/height)를 함께 저장해 다음 헤더·위치 변경에도 본체 기준을 유지한다. 보호 범위를 벗어난 수치는 즉시 적용값으로 표시하며 blur 때 반복 보정으로 값이 흐르지 않는다. 검증/캐시/복제/ZIP/실행취소와 실제 APK까지 연결했다. compilerVersion0.10.2로 이전 미리보기 캐시를 분리한다.

새 회귀는 첨부와 같은 가이드에서 짧은/긴 문장의 실제 글자 경계와 본체 색 픽셀, 고정32px 캐릭터, 양 플랫폼 본체 크기, 위치·겹침, 세부 편집/undo와 저장 원본 불변을 검사한다. 단위61개와 실제 APK/ktheme 검증이 통과했다. 실제 서버에서도 사용자 프로젝트를 저장하지 않고 긴 문장3줄이 본체 안에 있는 것을 확인했다. 실제 카카오톡 적용은 사용자가 확인하며 deviceVerified=false다.
