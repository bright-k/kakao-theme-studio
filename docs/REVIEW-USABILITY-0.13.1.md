## 설정 탐색과 작은 화면

현재 편집기에는 미리보기 클릭→설정 이동, 적용 원본/예외 표시, 공통 연결 복원, HEX 입력, 플랫폼 크게 보기, 실행취소가 이미 있다. 이 기능을 새로 추가하기보다 기존 기능의 위치와 기본 노출을 정리하는 편이 효과적이다.

- **핵심 설정을 먼저 보이기.** 테스트 샘플의 데스크톱 설정 패널은 표시 높이1018px에 스크롤 내용7908px이고, 말풍선 편집 시작점은 패널 상단에서 약1420px 아래였다. 공통 색상 전체 목록을 먼저 훑지 않아도 `말풍선 / 배경 / 입력창` 같은 작업 대상을 골라 핵심 설정에 도달하도록 한다. 고급 항목은 필요할 때 펼치되 같은 catalog-editor 인스턴스를 재사용한다.
- **적용 상태와 해결 동작을 같은 위치에 두기.** 단색 배경 패널은 플랫폼 예외가 있다는 안내만 있고, 그 자리에서 우선하는 설정으로 이동하거나 공통값에 연결하는 버튼이 없다. 테스트의 공통색 `#445566`보다 iOS 예외 `#AABBCC`가 우선했다. `현재 iOS에 적용된 색`과 `이 설정으로 이동`을 함께 보여 주면 설정이 반영되지 않는 이유를 빨리 알 수 있다. 기존 예외를 자동 삭제하지 않는다.
- **모바일에서는 한 플랫폼을 기본으로.** 390px에서 두 휴대폰을 나란히 보여 주면 글자가 매우 작고, 편집 패널은 페이지 상단에서 약1235px 아래에 시작한다. 작은 폭의 기본값은 iOS/Android 한 화면과 전환 탭으로 두고, 편집 중에도 미리보기로 쉽게 복귀하거나 함께 확인할 수 있게 한다. 주요 생성 동작이 다른 헤더 버튼에 밀려 보이지 않는지도 함께 정리한다.

## 다음 순위의 편집 편의

- `한 글자 / 짧은 문장 / 여러 줄`과 직접 입력한 미리보기 문장을 지원하면 사용자가 자신의 그림에 맞춰 검사하기 쉽다. 현재의 받은/보낸 첫·연속 네 상태는 유지하고, 미리보기 문구/상태는 프로젝트 출력 설정과 분리한다.
- 수정 전후 비교를 잠깐 눌러 볼 수 있으면 모서리·색·배치의 작은 차이를 확인하기 좋다. 실제 생성된 그림끼리 비교하며 사용자 원본을 다시 합성한 가짜 비교는 피한다.
- 최근 사용한 색상/프로젝트 색상 견본과 슬라이더의 정확한 숫자 입력을 함께 제공하면 색을 반복 사용하거나 이전 수치로 돌아가기 편하다.
- 제작 버튼 근처에 현재 저장/미리보기 반영/최근 생성 결과의 일치 상태를 모아 보여 준다. 기존 구형 compiler/revision 안내와 서명키 선택 흐름을 재사용해 별도의 승인 단계를 늘리지 않는다.

권장 진행 순서는 **마지막 편집 보존·오류 위치 표시 → 업로드 후 적용 상태 → 입력 단축키·실제 가독성 검사 → 설정 패널/모바일 정리 → 비교·색상 재사용**이다. 새 구현을 할 때 각 항목의 재현 사례를 회귀 검사로 옮기는 것이 좋다.
