# 0.4.0 상태·원본·시각 편집

화면을 고른 뒤 상태를 바꿔 리소스를 확인하고, 현재 적용되는 원본을 확인한 다음 늘림·여백을 그림 위에서 조정하는 흐름을 추가했다. 수정 가능한 카탈로그는 26.9.0 기준 105개 iOS 속성, 49개 Android 색상, 82개 이미지 그룹 / 146개 출력과 공통 원본 47개를 유지한다.

## 상태 미리보기

- 비밀번호 0~4자리와 누른 숫자 0~9, Android 패턴.
- 친구/채팅/지금/쇼핑/더보기/로컬/통화/만화 탭 아이콘. 지역 탭은 대표 탭 바의 가운데 위치에서 실제 이미지를 검토한다.
- Android 프로필 1~3과 전체 프로필 원본. iOS는 지원되는 기본 프로필만 표시한다.
- 첫/연속 말풍선과 iOS 선택 이미지·글자색. Android에 없는 선택 이미지를 임의로 만들지 않는다.
- 버튼·목록 기본/누름/선택, 기본/라이트 배너와 친구 추가 버튼의 실제 제공 상태.
- 상태 전환은 프로젝트 데이터와 빌드 입력을 변경하지 않는다.

## 적용 원본

출력별 재정의, 공통 원본과 대체 원본, 기본 생성, 이미지 비활성화, 원본 가이드/개별 편집을 표시한다. 공통 원본 행에는 직접 쓰이는 출력 수와 다른 원본/재정의가 우선하는 수를 표시한다. 판정은 파일별 소스 추적 메타데이터이며 모든 146개 출력의 단색 원본 픽셀 대조 테스트를 추가했다.

## 시각 편집

iOS 말풍선은 기존 stretch/insets 속성에 논리 1배수 좌표를 저장한다. Android는 선택한 파일 또는 같은 논리 그룹의 모든 배율에 resourceGeometry를 저장하며 원본 그림을 보존하고 가이드 테두리만 재생성한다. 여러 늘림 구간을 유지·추가·삭제할 수 있다. 드래그와 숫자 입력, 실행취소/다시실행, 원본/공통값 복귀, 프로젝트 복제·ZIP 백업/복원을 지원한다. iOS 선택/기본 상태가 공유하는 내용 여백도 명시한다.

## 확인 경계

미리보기는 대표 레이아웃이며 실제 카카오톡/iPhone 적용 검증은 미완료다. 가로·태블릿은 출력별 이미지와 가이드 검토를 지원하며 기기별 화면 전체를 재현하지 않는다. 생성 규칙 변경으로 compilerVersion을 0.4.0으로 올렸으며, 기존 프로젝트 선택 필드는 생략 가능하다. 테스트 데이터와 키는 사용자 데이터로 설치하지 않는다.
