# 0.9.1 캐릭터 사용 시 본체 과대 생성 수정

0.9.0에서도 캐릭터를 켜면 본체가 크게 부풀었다. 파라미터 변화만 검사하고 같은 설정의 켬/끔 본체 크기를 비교하지 않은 것이 이전 검증의 부족한 점이었다. 실제 이전 서버의 모서리18·좌우13·상하7·캐릭터32 조건은 끔56px/켬92px였다.

색상 본체는 모서리·꼬리에 필요한 고정 cap과1픽셀 늘림으로 압축 생성한다. bodyHeight와 세로 글자 여백은 캐릭터와 독립이고, 캐릭터 header만 위에 더한다. 본체 전체55픽셀을 글자 여백에 더하거나 padding 때문에 본체를 미리 확장하지 않는다. 이미지 본체의 원본64×56 기준과 수동 가이드/출력별 예외의 우선순위는 유지한다.

고정 cap에 필요한 내용 최소치는 가로1픽셀, 한 줄 높이16픽셀을 기준으로 한다. 고정 캐릭터를 담는 최소 가로 공간은 필요하며, 그보다 작은 여백 입력은 최소값으로 제한된다. UI에 공통 기준 본체 여백을 표시한다. 실제 카카오톡의 다른 폰트 크기·버전은 실기기 확인 대상이며 deviceVerified=false다.

공통 원본 승격은 모서리·꼬리를 보존하고 중앙 띠만 늘리거나 줄여64×56으로 반환한다. 헤더/본체는 겹치지 않으므로 PNG 픽셀을 직접 복사해 반투명 가장자리의 RGB 반올림 손실도 없앴다. 원본 자산과 사용자 설정은 변경하지 않는다. compilerVersion0.9.1로 이전 캐시를 분리한다.

새 bubble-body-size 검증은 실제 renderPlatform의 region과 본체 색 픽셀을 켬/끔 비교한다. 양 플랫폼·양 방향·색상/이미지 본체·3여백 조건에서 높이가 같다. 첨부와 같은 조건은 양쪽 모두47px이며 보이는 색 픽셀 높이도43px로 같다. 테스트 도형만 사용한 비교 캡처는 test-results/bubble-body-on-off.png다. 나머지 검증 및 실행 서버 반영은 VERIFICATION/HANDOFF를 따른다.
