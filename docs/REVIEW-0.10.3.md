# 0.10.3 공통 말풍선 이미지 적용과 플랫폼 설정

공통 본체 이미지를 등록해도 bubbleDesign.body가 color에 남아 생성기가 등록 이미지를 사용하지 않는 문제가 있었다. 실제 프로젝트에서도 공통 보낸 본체는 등록되어 있었지만 color 모드가 유지되고 있었다.

공통 본체 등록과 공통 원본 승격은 해당 첫/연속 본체를 이미지 모드로 전환한다. activateCommonBubbleBody를 API와 편집 UI에서 공유하며 iOS 수동 가이드는 기존 보정 경로를 사용한다. 다른 쪽·별도 연속 상태·캐릭터·플랫폼 이미지/기하 재정의는 유지한다. 선택 이미지에만 원본이 있는 경우에는 auto 모드로 원본 우선순위를 유지한다. 기존 프로젝트를 열 때 일괄 전환하지는 않는다.

이미 등록된 이미지는 본체 패널의 `등록한 공통 본체 적용`으로 다시 업로드하지 않고 활성화한다. 새 등록은 자동으로 전환되고 본체 방식에도 `등록한 이미지 사용`이 표시된다. 색상 모드로 돌아가도 이미지 원본은 보존한다.

같은 패널에 `iOS 이미지·늘림·여백`, `Android 이미지·9-patch·여백` 바로가기를 제공한다. 기존 catalog-editor의 해당 기본 말풍선 리소스 그룹을 열며 기본 대상은 해당 플랫폼의 모든 배율이다. 공통 이미지를 그대로 쓰고 가이드만 조절하거나 플랫폼별 다른 이미지를 올릴 수 있다. 출력 이미지 재정의가 공통보다 우선하며 사용자가 공통 연결을 복원하기 전에는 해제하지 않는다. 개별 이미지는 최종 말풍선 그림이므로 공통 캐릭터 합성보다 우선한다. 선택 상태 이미지는 기존 별도 상태 설정을 사용한다.

저장 형식과 슬롯은 그대로이며 compilerVersion0.10.3으로 캐시를 분리한다. 실제 사용자 프로젝트의 디자인 모드를 자동으로 변경하지 않고, 새 버튼과 공통 이미지 적용 경로만 읽기 전용으로 확인했다.
