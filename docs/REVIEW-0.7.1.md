# 0.7.1 짧은 메시지의 캐릭터 크기 보정

실제 iOS·Android 카카오톡에서 짧은 메시지의 캐릭터가 가로로 줄어든다는 보고에 따라 합성 말풍선의 자동 내용 여백을 보정했다. 캐릭터를 늘림 영역 밖에 두는 것에 더해, 글자가 짧아도 고정 영역을 담을 크기를 내용 여백으로 확보한다. 가로·세로 여백 합계는 해당 논리 크기에서 1픽셀 늘림 띠를 뺀 길이 이상이다. iOS CSS와 Android 9-patch가 같은 값을 사용한다.

미리보기도 생성 이미지와 출력 여백으로 크기를 계산하며 PNG의 최소 크기를 별도로 강제하지 않는다. 큰 캐릭터일수록 짧은 메시지의 빈 공간이 늘어나고, 긴 문장은 여백을 제외한 폭에서 줄바꿈한다. 기존 개별 가이드/이미지 우선순위와 비장식 말풍선은 유지한다. 원본/프로젝트 설정의 마이그레이션은 없고 compilerVersion 0.7.1로 이전 캐시를 분리한다.

전체 단위/API44개, 고정 크기32조합 픽셀 검증, 기존 편집기·화면·상태·공통 디자인 검증과 실제 두 플랫폼 빌드·서명·업데이트가 통과했다. VERIFICATION.md의 근거를 따른다. 실제 기기에서 수정 결과 확인은 사용자가 진행한다. deviceVerified는 false이며 기존 테마 파일은 서버 재시작·새로고침 후 다시 생성해야 한다.
