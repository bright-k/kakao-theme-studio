# 0.8.0 Android 17 대상·정확한 선택 영역·적용 장면 미리보기

구현일: 2026-10-26. 앱/컴파일러0.8.0이며 저장 포맷·카카오톡 출력 슬롯은 유지한다.

## Android APK

기존 코드는 설치된 SDK API를 targetSdk로 그대로 사용했고 이 환경에서는33이었다. [Android 공식 설정 문서](https://developer.android.com/about/versions/17/setup-sdk)의 Android17/API37을 기준으로 target37/min28을 명시했다. 공식 sdkmanager 목록에 있는 안정 Platform android-37.2와 Build Tools37.0.0을 추가 설치했다. doctor는 preview·rc를 제외하고 SDK/도구37 이상을 요구하며, 부족하면 구형 대상으로 생성하지 않고 설치 명령을 안내한다. JDK의 기존 개인 버전 fallback은 설치 목록 탐색으로 일반화했다.

최종 APK의 badging에서 target37/min28·ID·versionCode를 검사한다. 서명 이후 파일을 변경하지 않고 resources.arsc STORE/정렬과 기존 fingerprint 연결을 유지한다. 안내 Activity는 dp와 시스템 WindowInsets로 최신 Android의 화면 가장자리를 고려한다. target 업데이트는 테마 배포 APK의 대상 정책이며 카카오톡의 자체 버전이나 레이아웃을 바꾸지 않는다.

## 선택 영역

휴대폰 부모의 border box에서 계산한 위치를 절대 좌표 padding box에 넣으면서 border가 이중 반영된 것이 첨부와 같은 일정한 위치 차이의 원인이었다. preview-interaction은 border·스크롤·CSS 배율을 보정한다. 탭/비밀번호는 실제 이미지 사각형, 글자는 폰트 측정값, 대화 내용은 실제 clip으로 hit를 기록한다. 캐릭터는 drawNine과 동일한 정수 slice 배치로 투영해 가이드에 따른 이동도 반영한다. 선택 테두리는 Canvas 밖 DOM이므로 PNG 내보내기에 들어가지 않는다.

## 적용 맥락과 사용성

- 앱 안 새 메시지 알림: 채팅 목록 위 알림 카드. 배경/이름/내용을 각각 선택한다. 휴대폰 시스템 알림과 구분한다.
- 메시지 전달 안내: 대화방 위 안내 배너와 대화방 이동 글자. 실제 생성한 말풍선·배경·프로필을 사용한다.
- 친구 추가·공통 버튼: 전화번호 추가 흐름의 버튼과 추천 친구 추가 아이콘. 기본/누름/선택 상태를 비교한다.
- 탭 위 안내 배너: 하단 탭 위 안내의 기본/라이트 배경. 광고 이미지 교체와 구분한다.

각 장면 위에 적용 대상을 설명하고 그림에서 기존 catalog-editor의 속성으로 이동한다. 팔레트는 개별 속성 편집 때문에 바뀌지 않는다. 장면·상태·플랫폼 보기는 저장되지 않는다. 플랫폼 크게 보기, 모바일390px 레이아웃, 관련 상태만 노출, 작은 대상의 선택 목록, 포커스 표시와 선택 유지도 개선했다. 비편집 시연 글자는 대비를 확보하며 실제 앱의 모든 고정 글자색/배치와 일치한다고 주장하지 않는다.

## 검증과 적용

단위/API45개, 새 적용 장면/정렬 검증, 캐릭터32조합/선택 영역 픽셀 대조, 기존 공통 디자인·상태·화면·상세 편집·전체 제작 브라우저와 실제 두 플랫폼 빌드·서명·동일키 업데이트가 통과했다. 좌표는 양 플랫폼·1520/800/390px·소수점 프레임·scale.83에서 독립된 버튼 그림 기준 오차0.12CSSpx 미만이다. 새 장면/모바일/선택 캡처를 육안 확인했다. 근거는 VERIFICATION.md다.

사용자 프로젝트·원본·키·기존 빌드와 실행 서버는 변경하지 않았다. 서버를 종료하고 현재 폴더의 Studio.command를 다시 실행한 뒤 새로고침·테마 재생성이 필요하다. 실제 Android17 기기 설치·카카오톡 테마 적용은 이번에 확인하지 않았으며 deviceVerified=false다. 사용자가 실기기 적용 확인을 진행한다.
