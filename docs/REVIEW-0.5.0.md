# 0.5.0 공통 디자인·미리보기 선택·캐릭터 말풍선

구현일: 2026-10-26. 앱과 compilerVersion은 0.5.0이다. 26.9.0 카탈로그의 iOS 105개 속성, Android 49개 색상, 82개 이미지 그룹 / 146개 출력을 유지하며 공통 원본은 51개다.

## 공통 제작

화면별 공통 디자인을 펼쳐 두고 역할별 검색, 원본 썸네일, 지원 플랫폼과 출력별 적용 목록을 제공한다. 공통 원본 교체는 assets의 연결을 갱신하며 기존 출력별 재정의를 자동으로 지우지 않는다. 적용 목록에서 개별 출력들을 골라 공통 원본으로 연결할 수 있고 실행취소/다시실행을 지원한다. 크롭·사용 여부와 개별 resourceGeometry는 유지한다. 원본 .9.png 재정의를 해제할 때 원본 가이드는 resourceGeometry로 보존한다.

세부 이미지의 `이 이미지를 공통 원본으로 사용`은 생성된 그림을 공통 원본으로 등록한다. Android 가이드 테두리는 제외하며, 합성 말풍선은 상단 캐릭터를 제외한 본체를 추출한다. 기존 개별 출력은 유지하므로 적용 목록에서 필요한 것만 연결한다. 전체 리소스 템플릿 ZIP은 출력별 세부 편집용이며 재등록한 출력이 공통 원본보다 우선한다.

## 미리보기에서 설정 찾기

렌더러가 실제 그리는 사각형과 같은 위치에 선택 대상을 기록한다. 배경·프로필·말풍선·캐릭터·탭·비밀번호 표시·키패드·입력창·배너·버튼을 누르면 관련 공통 설정 또는 기존 catalog-editor의 정확한 속성/출력으로 이동한다. 긴 메시지·첫/연속·선택·프로필·지역 탭 등의 현재 상태를 반영한다.

마우스 호버는 별도 DOM 오버레이로 영역과 이름을 표시하므로 내보내는 미리보기 PNG에는 선택 테두리가 들어가지 않는다. CSS 축소 좌표를 변환하며 `수정할 부분` 선택 목록으로 키보드/터치 탐색도 지원한다. 역할별 공통 검색과 공식 속성/영역 검색으로 다른 화면의 설정도 찾을 수 있다. 클릭만으로 프로젝트·실행취소 이력·생성 입력을 바꾸지 않는다. 가로/태블릿/개별 배율은 기존 전체 이미지 목록에서 검토한다.

## 말풍선 본체와 캐릭터

보낸/받은 쪽 각각에 첫 번째/연속 탭을 제공한다.

- 본체: 색상 생성, 등록 이미지, 기존 원본 자동 사용. 연속은 첫 번째와 같은 설정도 선택할 수 있다. 이미지 원본은 모드 전환 시 보존한다.
- 캐릭터: 첫 번째는 독립 사용 여부, 연속은 사용 안 함 / 첫 번째 원본 공유 / 연속 전용 원본. 전용 업로드 시 해당 모드로 전환한다.
- 각 상태의 색상·본체 이미지·캐릭터·위치·크기·간격을 독립적으로 설정한다. 이미지 모드의 색/모서리는 원본을 따른다. 글자색은 플랫폼이 제공하는 속성에 따라 첫/연속이 공유하며 개별 플랫폼 재정의가 우선한다.
- 색상 본체는 이미지 업로드 없이 생성한다. 장식은 비율을 보존해 지정한 정사각 영역 안에 맞추며 불필요한 투명 여백을 임의로 잘라내지 않는다.

편집 입력은 분리하고 실제 출력은 하나의 말풍선 그림으로 합성한다. 장식은 상단 좌/우 고정 영역에, 늘림 지점은 장식 바깥의 본체에 둔다. 장식 높이를 포함한 내용 여백을 iOS 속성과 Android 9-patch에 반영한다. 본체 원형은 64×56이며 합성 출력은 장식 크기/간격에 맞게 논리 폭·높이가 확장된다. 따라서 큰 장식은 최소 말풍선 폭과 메시지 위쪽 공간을 늘린다. 장식 중앙 고정·자유 중첩·애니메이션은 지원하지 않는다.

## 데이터와 우선순위

schemaVersion 1의 선택 필드 `bubbleDesign.sent/received`와 그 안의 `group`이 디자인을 저장한다. 새 네 공통 슬롯은 sentBubbleDecoration / receivedBubbleDecoration / sentBubbleGroupDecoration / receivedBubbleGroupDecoration이다. 기존 첫/연속 본체 슬롯과 iOS 선택 슬롯은 그대로 유지한다.

새 필드가 없는 프로젝트는 이전 생성 경로를 사용한다. 공통 합성보다 resourceOverrides가 우선한다. Android 원본 .9.png와 resourceGeometry, iOS 명시적 늘림/내용 여백도 우선하며, 기존 개별 가이드가 있으면 장식 영역과 겹치는지 세부 편집에서 확인해야 한다. iOS 선택/기본 이미지가 내용 여백을 공유하는 제약도 유지한다. UI에서 장식 크기/상태를 바꿀 때 iOS 명시적 좌표는 본체 기준으로 이동·제한해 저장 범위를 유지한다.

원본 추적은 본체와 장식의 기여를 따로 기록한다. 검증, visualRevision 캐시, 복제, 실행취소, 원본 참조, ZIP 백업/복원이 새 설정과 이미지를 포함한다. 키와 package ID/fingerprint 연결은 바꾸지 않는다. 기존 프로젝트/예제/사용자 결과를 일괄 마이그레이션하거나 덮어쓰지 않는다.
