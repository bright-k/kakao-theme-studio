# 0.10.0 캐릭터 위치·겹침과 슬라이더

말풍선의 보낸/받은·첫/연속 공통 디자인에서 캐릭터의 좌우 위치, 세로 간격/겹침, 앞뒤 순서를 조절한다. iOS와 Android는 같은 정책을 사용하고 기존 출력별 이미지·가이드 예외가 우선한다. 앱/컴파일러는0.10.0이다.

`캐릭터 크기·위치`의 슬라이더는 현재 값을 오른쪽에 표시한다. 좌우 음수는 바깥쪽, 양수는 안쪽이다. 세로 음수는 본체와 겹침,0은 맞닿음, 양수는 위로 띄움이다. 크기와 개별 모서리도 같은 범위 입력을 쓴다. 위치 범위는 고정 그림·글자 보호에 필요한 현재 안전 범위로 한정하며 양쪽 끝에 방향 설명을 표시한다. 키보드 화살표와 Home/End를 지원한다. 캐릭터 선택 후 미리보기에서 드래그할 수도 있다. 드래그 중에는 안내 테두리만 이동하고 놓을 때 한 번 저장하며 Escape/취소는 저장하지 않는다.

선택 필드 `shiftX`(−72~72), `placementY`(−24~24), `layer`(front/back)를 bubbleDesign의 첫/연속 설정에 추가했다. 필드가 없으면 shiftX0, 기존 gap, front다. 기존 offset은 기준 배치와 원본 크기 계산을 보존하며 새 이동값과 분리했다. 첫/연속은 공유 원본이라도 위치를 따로 지정할 수 있다. 보낸/받은의 좌/우 모서리 전환도 본체 폭을 바꾸지 않도록 기준 cap을 대칭으로 계산한다.

`bodyWidth/bodyRect/bodyInsets`는 본체 자체를 나타낸다. 바깥 돌출은 전체 PNG 폭과 출력 인셋에만 더하고, 세로 간격은 header만 바꾼다. 본체 크기·내부 글자 여백은 이동/겹침/앞뒤와 독립이다. 미리보기는 줄바꿈 폭에서 바깥 투명 여백을 제외하고 본체의 기준 위치를 고정한다. 정수 폭으로 그려 외부 여백 때문에 nine-slice의 반올림 경계가 변하는 것도 막는다. 전달 장면과 선택 영역도 같은 경계를 사용한다.

늘림 띠를 넘는 안쪽 이동과 글자 영역을 가리는 깊은 겹침은 안전 범위로 제한한다. 큰 이동을 허용하려고 본체를 키우지 않는다. 투명 여백이 많은 원본은 눈에 보이는 그림과 사각형 경계가 다를 수 있으며 원본을 자동으로 자르지 않는다. 실제 앱의 프로필·이웃 메시지와의 배치는 기기 확인 대상이다.

겹침은 알파 합성하며 투명 픽셀이 본체를 지우지 않는다. 본체를 공통 원본으로 승격할 때는 캐릭터 전 본체를 다시 생성해 겹친 캐릭터를 섞지 않는다. 기존 캐릭터 없는 원본·출력별 예외·수동 가이드·캐시·복제·ZIP·이력을 유지한다.

검증은 VERIFICATION.md를 따른다. 단위54개, 실제 production 렌더러의 본체/텍스트/캐릭터 픽셀 불변, 슬라이더/키보드/드래그/취소/undo, 기존 화면·저장·제작 흐름과 겹침을 넣은 실제 APK/ktheme를 확인했다. 실제 카카오톡 적용은 사용자가 확인하며 deviceVerified=false다.
